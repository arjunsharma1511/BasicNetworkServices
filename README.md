# Packet Harbor — Network Basics and Services Lab

A dependency-free 60-minute browser lab about IPv4 addresses, network services, ports, protocols, and basic traffic analysis.

## GitHub Pages files

- `index.html`
- `styles.css`
- `app.js`

Keep those three files together. No packages or build step are required.

## Instructor file

- `INSTRUCTOR-ANSWER-KEY.txt`

The answer key contains every answer, reasoning, timing, facilitation prompts, and completion standard. Keep it out of the student-facing GitHub Pages upload if answers should remain private.
