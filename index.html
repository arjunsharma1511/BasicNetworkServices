BRIEFING ONE

One conversation needs two destinations

The IP address identifies the device. The port identifies the service on that device.

WHAT

IP address

A numeric address assigned to a network interface. IPv4 uses four decimal numbers from 0 to 255, separated by dots.

192.168.10.42
WHY

Device delivery

Routers examine destination IP addresses so packets can travel toward the correct network and device.

Destination device
HOW

Packet routing

The sender adds source and destination IP addresses. Network devices forward the packet along an available route.

source → destination

Private IPv4

Used inside private networks. Common ranges begin with 10., 172.16–172.31., or 192.168.

Public IPv4

Used for internet routing. An organisation may translate private addresses to a public address at its router.

Loopback

127.0.0.1 means “this computer.” It lets software contact a service on the same device.

Default gateway

The router a device sends traffic to when the destination is outside its local network.
